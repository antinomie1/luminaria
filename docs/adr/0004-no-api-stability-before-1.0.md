# 1.0 之前不承诺任何 API 稳定性

明确写在 README 第一屏：本库 pre-1.0，API 与 ABI 都会变，下游请锁 commit。

## 为什么

"API 简洁明了"这个目标要有人买单——每一次简化都是一次 break。而已经排上日程的几件事
（删场景树、切四个 module、`Surface` 换代际句柄、三个协议移出核心）**每一条都是 break**。
现在承诺稳定性等于给自己上镣铐，结果只会是把简化留在原地。

wlroots 被抱怨的"每个版本下游都要改"，真正的问题不是它会变，是它**从没说清楚它会变**。
把话说在前面，成本就从下游的意外变成下游的选择。
